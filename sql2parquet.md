## Утилита командной строки на GO для экспорта результата команды SQL в файл формата parquet

# Аргументы командной строки

* -D <имя базы данных>
* -d oracle | postgres драйвер базы данных
* -с <строка соединения>
* -u <имя пользователя>
* -p <пароль пользователя>
* -P <порт>
* -H <хост>
* -S <команда SQL>
* -o <имя выходного файла parquet>

# Нефункциональные требования

* Утилита должна работать с большими запросами, ответ на которые превышает объем доступной памяти
* Утилита загружает данные из базы и записывает в файл в паралелльных потоках
